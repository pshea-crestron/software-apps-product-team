## Workflow & Dev Guidance
1. **Iterative Flow**: The prototypes are a rapid-iteration frontend tools. All logic and layouts must match the capabilities listed in the PRD and user stories mapped above.
2. **Asset Preservation**: Do not delete, overwrite, or misplace icons and mock images located inside the `./configure-pro-av-tool-mock-v2/assets/` directory when editing the HTML.
3. **Vanilla Tech Stack**: Keep adjustments inside standard HTML5, CSS3, and vanilla modern JavaScript (`support.js`) unless explicitly instructed. Do not inject heavy framework dependencies (like React or Vue) into this mockup environment.
